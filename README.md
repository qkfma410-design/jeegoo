# 안동과학대학교 대학혁신사업단 성과관리 대시보드 (Netlify 배포판)

GitHub에 올리고 Netlify로 배포하는 버전입니다.
**접속 코드나 PIN 없이** 주소를 아는 사람은 누구나 대시보드를 보고 실적을 입력할 수 있습니다.

- 지표별 진척률 도넛, 연차별 목표·실적 표, 하위지수 진척, 정의서 정비사항
- 실적 입력: 누구나 저장 가능하며, 입력자 이름이 이력에 남습니다
- **저장 이력·되돌리기**: 최근 100건을 보관하고, 원하는 시점이나 초기값으로 되돌릴 수 있습니다
- AI 요약보고서(공유·메일·메신저 복사·PDF 저장·인쇄), 다크 모드, 실시간 날짜

## 구조

```
├─ public/                  ← 화면 (Netlify가 그대로 게시)
│   ├─ index.html, style.css, app.js, report.js, logo.png
│   └─ seed-data.json       ← 지표 정의: 기준값·목표·가중치·집계 시점·정비사항 문구 + 초기(가상) 실적
├─ netlify/functions/api.mjs ← 실적 저장 서버 함수 (Netlify Blobs 사용)
├─ netlify.toml             ← 배포 설정
└─ package.json
```

- **지표 정의**는 저장소의 `public/seed-data.json`에 있습니다.
- **입력된 실적**만 Netlify Blobs(Netlify 내장 저장소)에 저장됩니다.
- 그래서 정의서가 바뀌어 `seed-data.json`을 고쳐 다시 배포해도, 이미 입력된 실적은 그대로 유지됩니다.

## 배포하기

### 1단계. GitHub에 저장소 만들기

1. https://github.com 에 로그인 → 오른쪽 위 `+` → **New repository**
2. Repository name: 예) `asc-performance-dashboard`
3. **Private**(비공개)를 권장합니다. 지표 정의와 초기 데이터가 저장소에 들어 있기 때문입니다. Netlify는 비공개 저장소도 배포할 수 있습니다.
4. **Create repository**
5. 생성된 페이지에서 **uploading an existing file** 링크를 누르고, 이 폴더 **안의** 파일과 폴더(`public`, `netlify`, `netlify.toml`, `package.json`, `README.md`, `.gitignore`)를 모두 끌어다 놓은 뒤 **Commit changes**
   - 폴더째 끌어다 놓으면 하위 폴더 구조가 유지됩니다.
   - `.gitignore`는 숨김 파일이라 안 보일 수 있습니다. 빠져도 동작에는 문제없습니다.
   - 올린 뒤 저장소 첫 화면에 `netlify.toml`과 `public` 폴더가 바로 보여야 합니다. 한 단계 더 들어간 폴더 안에 있으면 배포가 되지 않습니다.

### 2단계. Netlify에 연결하기

1. https://app.netlify.com 에 로그인 (GitHub 계정으로 가입하면 편합니다)
2. **Add new project**(또는 Add new site) → **Import an existing project** → **GitHub**
3. GitHub 권한을 허용하고 1단계에서 만든 저장소를 선택
4. 빌드 설정은 `netlify.toml`에서 자동으로 채워집니다. 그대로 두고 **Deploy** 를 누릅니다.
   - Publish directory: `public` / Functions directory: `netlify/functions`
5. 1~2분 뒤 `https://(이름).netlify.app` 주소가 생깁니다. 이 주소를 공유하면 됩니다.
   - 주소 이름은 `Project configuration › Change project name`에서 바꿀 수 있습니다.

Netlify Blobs는 따로 켤 필요 없이 함수에서 자동으로 사용됩니다. 처음 접속하면 초기(가상) 실적이 보이고, 누군가 처음 저장하는 순간부터 저장된 실적이 표시됩니다.

### 3단계. 확인

- 대시보드가 열리고 상단에 **자동 갱신 중**(초록 점)이 보이면 정상입니다.
- '저장된 실적을 불러오지 못해 초기값을 표시합니다'가 나오면 서버 함수가 배포되지 않은 것입니다. Netlify의 `Deploys`에서 배포 기록과 오류를 확인해 주세요.

## 사용하기

### 실적 입력과 되돌리기

1. 왼쪽 메뉴 **실적 입력** → 입력자 이름을 적고 하위지수 실적을 고친 뒤 **저장**
2. 다른 사람 화면에는 **1분 안에** 반영됩니다. 창을 다시 보거나 새로고침하면 바로 반영됩니다.
3. 동시에 고치다가 다른 사람이 먼저 저장하면, 내 입력은 그대로 둔 채 안내가 나옵니다.
4. 아래 **저장 이력**에서 원하는 시점의 **이 시점으로 되돌리기**, 또는 **초기값으로 되돌리기**를 누릅니다. 되돌리기도 이력에 남으므로 다시 되돌릴 수 있습니다.

### 지표 정의 고치기 (기준값·목표·가중치·문구)

1. GitHub 저장소에서 `public/seed-data.json` → 연필 아이콘(Edit)
2. 값을 고치고 **Commit changes** → Netlify가 자동으로 다시 배포합니다 (1~2분).
3. 입력된 실적은 유지됩니다. 단, 하위지수 키(Ⓐ·Ⓑ·Ⓒ)나 지표 `id`를 바꾸면 그 항목의 저장된 실적은 연결되지 않습니다.

자주 고치는 항목:

| 항목 | 위치 |
|---|---|
| '가상 실적 · 검증 전' 표시 없애기 | `meta.dataNote`를 `""`로 |
| 사업연도·기간 | `meta.yearLabel`, `meta.yearStart`, `meta.yearEnd` |
| 상태 판정 기준 | `thresholds` (기본: 정상 60, 주의 30) |
| 정비사항·유의사항 문구 | `issues`, `cautions` |

### AI 요약보고서

오른쪽 위 **AI 요약보고서** 버튼을 누르면 현재 데이터로 보고서가 팝업으로 열립니다. 메일로 보내기, 메신저용 복사, PDF 저장, 인쇄를 쓸 수 있습니다. 보고서는 대시보드 데이터를 정해진 규칙으로 분석해 작성하며, 외부 AI 서비스로 데이터를 보내지 않습니다. `https` 주소라서 휴대폰에서는 **공유하기** 버튼도 나타납니다.

## 꼭 알아 두세요

- **누구나 고칠 수 있습니다.** 주소를 아는 사람이면 학교 밖에서도 실적을 바꿀 수 있습니다. 주소는 필요한 사람에게만 알려 주세요.
  - 잘못 바뀌면 저장 이력에서 되돌릴 수 있습니다. 다만 이력은 최근 100건만 보관하므로, 짧은 시간에 저장이 100번 넘게 반복되면 그 이전 기록은 지워집니다.
  - 중요한 시점(분기 마감 등)에는 실적 입력 화면의 **데이터 내보내기**로 파일을 받아 두세요.
  - 접근을 제한해야 할 때는 Netlify의 사이트 비밀번호 보호(유료 요금제 기능)나 Netlify Identity 같은 로그인 기능을 추가로 검토하세요.
- **사용량**: 화면을 켜 두면 1분마다 서버 함수를 한 번 호출합니다(화면이 보일 때만). 몇 명이 함께 쓰는 정도는 무료 요금제로 충분하지만, 많은 사람이 하루 종일 켜 두면 Netlify 사용량 한도에 닿을 수 있습니다. `Usage`에서 확인할 수 있습니다.
- 글꼴(IBM Plex Sans KR)은 Google Fonts에서 불러옵니다.

## (선택) 내 PC에서 미리 보기

Node.js가 설치된 PC에서:

```bash
npm install
npx netlify-cli dev
```

`http://localhost:8888`에서 열립니다. 이때 저장되는 실적은 PC 안의 임시 저장소에만 들어가고 배포된 사이트와는 따로입니다.
